最简单的用法（推荐）
--------------------
在家/办公室：电脑和手机连同一个 Wi-Fi，电脑端「手机连接」弹窗点「开启」→
「复制连接地址」，把地址发到手机 App 粘贴即可。不需要 Tailscale 账号，
也不用生成 key。只有人在外面、手机用流量时，才需要看下面的 Tailscale 部分。

2.4.16 改进
-----------
- 完整离线包仍内置 Alpine、Node/npm 和 Claude Code；新用户首次安装不需要
  下载环境，也不用为此开 VPN。已装环境的用户可用 2.4.16 精简包，约 8 MB。

隐私边界（务必看）
------------------
- 无障碍权限本身很大：开启后，Claude 能读取当前屏幕上的可见文字、控件和
  普通界面截图。这些内容会作为工具结果发给 DeepSeek 模型，并按 DeepSeek
  的隐私政策处理；本 App 不会把屏幕内容上传到开发者自己的服务器。
- 上面的密码/卡号/验证码过滤是保护措施，不是绝对安全边界；非标准控件、
  英文界面、验证码拆成多个控件等情况仍可能漏过。进入银行、支付、输入密码
  或验证码的步骤，最安全的做法是关掉手机控制或自己手动完成。
- 本 App 无 root，不能读其他 App 的私有数据，也没有短信/通讯录权限；但如果
  Claude 打开短信或通知栏，屏幕上的验证码仍可能被读到，所以验证码步骤要手动。
- 手机控制 HTTP 接口只监听 127.0.0.1，并带随机 token；手机端 Node 只监听
  127.0.0.1，内置 Tailscale 只向外连电脑，不会把手机控制端口暴露到网络。
- 不需要时在 App 的「手机控制」里点关闭，或到系统设置关掉无障碍；
  清空数据/卸载会删除 API Key、对话记录和手机端环境。

2.4.3 改进：无障碍不用每次重开
------------------------------
Android 出于安全限制，不允许普通 App 自己打开无障碍。系统在重装/强制停止/
省电清理后可能会把开关收回，所以之前每次都要去设置里点一遍。

现在可以一次性授权，让 App 自己保持：
1. 手机打开 设置 → 关于手机 → 连续点「版本号」7 次，开启开发者选项；
   再到 开发者选项 → 打开「USB 调试」。
2. 用数据线连接电脑，手机弹出「允许 USB 调试」时点允许。
3. 在电脑上双击运行 pc\授权无障碍自动保持.cmd（需要 adb，脚本会自动找
   E:\AI_Claude\android-sdk\sdk\platform-tools\adb.exe）。
4. 看到「完成」即可拔线。以后系统关掉无障碍后，打开 Claude 工作台会自动
   重新开启；开机也会自动恢复。

不想连电脑时，也可以尽量在系统里减少被收回：
- Android 13+ 侧载应用：系统设置 → 应用 → Claude 工作台 → 右上角 ⋮ →
  允许受限设置。
- iQOO/OriginOS：设置 → 电池 → 后台耗电管理 → Claude 工作台 → 允许后台高耗电；
  i管家 → 应用管理 → 自启动 → 允许；最近任务里给 App 加锁；关闭「权限自动回收」。
- 每次覆盖安装新 APK 后，Android 仍会关闭一次无障碍；用上面的授权后，
  打开 App 会自动恢复。

  切换页面时的握手开销。
- 5G / 蜂窝网络下不再先探测家里 Wi-Fi 地址，而是直接启动内置 Tailscale；
  外出打开电脑端大约少等 8 秒。
- 上次用的是电脑端、当前又在 5G 时，App 启动后会在后台预连接内置 Tailscale；
  点「电脑端」时通常已经连好，不用再等 tsnet 登录。
- 连接日志会显示「直连」或「中继 sfo / lax」。
  手机 5G 如果是运营商对称 NAT，Tailscale 无法打洞，只能走中继；
  这是线路限制，缓存和压缩只能改善观感，无法达到家里 Wi-Fi 直连的速度。
- 内置 Tailscale 的 Go 进程由 2 核提高到 4 核。
- 电脑端地址、手机端环境、对话记录都保留，直接覆盖安装即可。

手机 5G 直连电脑（IPv6，重要）
------------------------------
如果日志显示「中继 sfo」，说明手机 5G 和电脑之间没有直连，页面会有明显延迟。
手机 5G 通常是对称 NAT；电脑 IPv4 如果是运营商 CGNAT，做端口映射也没用
（本机路由器 WAN 就是 100.66.x.x，所以端口映射这条路不通）。

更快的办法是让电脑和手机都走公网 IPv6：
1. 电脑运行 `claude-remote\pc\开启IPv6直连.cmd`（会弹一次 UAC）；
   脚本只开启网卡的 IPv6，不做端口映射。
2. 输出里应出现 240e / 2001 开头的公网 IPv6；`tailscale netcheck` 应显示 IPv6: yes。
3. 手机打开电脑端，日志应变成「直连」。
4. 如果脚本提示没有公网 IPv6，需要在路由器后台开启 IPv6 / IPv6 双栈。

本机已经开启并验证过：Tailscale 状态里 `claude-phone` 出现过
`active; direct [240e:...]`，说明直连已经建立。手机 App 在后台被系统暂停时
会显示离线；使用电脑端时保持 App 在前台即可。

主页两种模式
------------
打开 App 先到主页：
- 电脑端：原来的远程模式，加载电脑「远程访问.cmd」打印的地址，行为和旧版一样。
- 手机端：在这台手机上用 proot + Alpine 跑 Node 和 Claude Code，不依赖电脑。

电脑端需要填什么
----------------
电脑端填电脑上「远程访问.cmd」窗口打印的手机地址，例如：
  家里 Wi-Fi：http://192.168.x.x:4711/m/index.html?token=你的令牌
  出门 Tailscale：https://电脑名.xxxxx.ts.net/m/index.html?token=你的令牌

注意：在手机上填 127.0.0.1 只会指向手机自己，不是电脑。
手机端不需要填电脑地址；手机端只用 DeepSeek API Key。

电脑端多地址（推荐）
--------------------
一次把「远程访问.cmd」打印的两行都粘进配置框，可以连前面的标签一起粘；
App 会提取所有 http/https 地址，每次打开按顺序探测，哪个能通就用哪个。
建议配置：
- 家里 Wi-Fi 地址：http://192.168.x.x:4711/...
- Tailscale 地址：http://100.x.x.x:4711/... 或 https://电脑名.xxx.ts.net/...
这样换 Wi-Fi / 5G 不用重新输入；当前能用的地址会自动排到第一。

Tailscale：两种方式
-------------------
方式 A：继续用现有 Tailscale App（不新增安装）
在 Android 设置里把 Tailscale 设为「始终开启 VPN」：
设置 → 网络和互联网 → VPN → Tailscale → 始终开启 VPN（不同品牌路径略不同）。
再在 Tailscale App 里允许后台运行/开机启动。这样出门切 5G 时它会自动保持连接，
App 探测到家里 Wi-Fi 不通后会直接走 Tailscale 地址，不需要手动打开 App。

方式 B：内置 Tailscale（不用装 Tailscale App，2.2.0+）
1. 打开 Tailscale 后台 → Settings → Keys → Generate auth key，生成一个 reusable key
   （如果 tailnet 开了设备审批，稍后要批准 claude-phone）。
2. App 主页 →「设置与日志」→「内置 Tailscale：未配置」。
3. Auth key 粘贴进去；电脑地址填电脑的 Tailscale 完整地址（带 token），例如：
   http://100.x.x.x:4711/m/index.html?token=...
   或 https://电脑名.xxx.ts.net/m/index.html?token=...
4. 点「保存并启动」；首次会以 claude-phone 加入 tailnet，可能需要在 Tailscale 后台批准。
5. 之后电脑端会先试已配置的 LAN/Tailscale 地址，都不通才启动内置代理。
   内置代理监听 127.0.0.1:4720，不占 Android VPN，也不需要安装 Tailscale App。
6. 成功后设备状态保存在手机，auth key 可以留空；auth key 只在本机，不要发给别人。
注意：内置代理运行在 App 的 proot 里；首次启动会复制约 20 MB 的 tsproxy，
不需要重新下载 Claude/Node。若失败，看运行日志里的 [tsnet]/[proxy]；也可以继续用方式 A。

手机端第一次使用
----------------
1. 点「手机端」，填写 DeepSeek API Key：
   - Base URL 默认 https://api.deepseek.com/anthropic
   - 模型默认 deepseek-flash[1m]
   - 推理档位默认 max（想省 token 可改 low/medium/high）
2. 点「安装手机端环境」：
   - 首次下载约 500 MB（Alpine + Node + Claude Code），需要 1.8 GB 以上空间；
   - 建议 Wi-Fi，安装期间可以点「后台安装」去做别的；
   - 下载源优先 Anthropic 官方 storage.googleapis.com，失败会依次回退
     claude.ai 安装脚本和 npm 国内镜像；
   - 安装完成后自动打开手机端页面。
3. 手机端页面右下角有一个 ⌂ 浮钮，随时回主页切换电脑端/手机端。

开启手机控制（无障碍点按）
--------------------------
1. 主页 →「设置与日志」→「手机控制：未开启」。
2. 点「开启」；如果还没授权，会跳到系统无障碍设置。
3. 在系统设置里找到「已下载的应用 / Claude 工作台」，打开无障碍开关。
4. Android 13+ 侧载应用如果开关是灰的：
   系统设置 → 应用 → Claude 工作台 → 右上角 ⋮ → 允许受限设置，
   再回到无障碍设置打开。
5. 回到 App，主页状态会显示「手机控制：已开启」。

之后在手机端对话里直接说人话，例如：
- “先看看当前屏幕，告诉我有哪些按钮。”
- “打开微信，找到文件传输助手，发一句‘测试’。”
- “打开设置，把亮度调低一点。”
Claude 会先用 phone_ui 读屏，再用 phone_tap_text / phone_type / phone_open_app 等执行。

敏感操作会停下来：
- 密码框、支付、转账、验证码等工具会返回 needsUser，Claude 必须把手机交还给你。
- 只在你需要自动化时开启；不用时在同一菜单点「关闭」，控制接口立即停止。

手机端文件位置
--------------
- /workspace：App 私有工作区（Android 里对应
  /data/user/0/com.missyao.claudeworkbench/files/linux/workspace），
  不是手机文件管理器里能直接看到的目录；新对话默认在这里。
  卸载 App / 清除应用数据会删除它；重装手机端环境不会删。
- /sdcard：手机存储。在主页「设置与日志」里授予「所有文件访问」后，
  它对应 /storage/emulated/0，可以选 Download、Documents、相册目录等；
  不授权时它只是 App 专属外部目录。
  操作步骤：
  1. 主页 →「设置与日志」→「手机存储：授权全盘访问」；
  2. 回到 App，在「设置与日志」里停止手机端，再启动一次（重新绑定 /sdcard）；
  3. 新对话 →「浏览手机文件夹」→ 选 /sdcard/Download 等 →「选择此文件夹」。
  也可以直接点新对话列表里的 sdcard。
- 对话记录在 App 私有目录的 ~/.claude/projects，重新安装会先备份再恢复。

省电/保活设置（OriginOS 必做）
------------------------------
1. 设置 → 电池 → 后台耗电管理 → Claude 工作台 → 允许后台高耗电。
2. i管家 → 应用管理 → 自启动 → 允许。
3. 最近任务卡片下拉锁定，防止一键清理。
4. 关闭省电/超级省电模式。
5. 长任务仍被杀时，可用 adb 执行一次：
   adb shell settings put global settings_enable_monitor_phantom_procs false

常见问题
--------
- 安装下载很慢/像卡住：2.1.1 会实时写百分比；GCS 低于约 40 KB/s 持续 15 秒
  会自动切换 claude.ai / npm 国内镜像。如果 npm 镜像也慢，再开 VPN 走官方 GCS。
- 安装时报下载失败：换 Wi-Fi/代理重试；三个下载源都不通时需要能访问
  storage.googleapis.com 或 claude.ai 的网络。
- 手机端启动失败：主页「设置与日志」→「查看运行日志」（每秒自动刷新），
  把 phone.log 发出来。
- 手机控制工具不可用 / Claude 说“未开启”：
  检查「设置与日志 → 手机控制」是否已开启，以及系统无障碍里 Claude 工作台是否打开。
- 无障碍开关是灰的：按上面 Android 13+ 的「允许受限设置」操作。
- 点按没反应：部分界面（游戏、视频、安全键盘）不暴露无障碍节点；
  可以让 Claude 用 phone_screenshot 看截图，或改用坐标点按。
- 签名不一致：先卸载旧版再装（电脑上的对话记录不受影响；手机本地对话会丢）。
- 想省电：不用时在「设置与日志」里停止手机端；前台服务会常驻通知。

安全
----
- API Key 存在 App 私有目录的配置里，不要截图/分享。
- 手机端只监听 127.0.0.1，不对外开放端口；控制接口另有随机 token。
- 无障碍权限能读取屏幕上的文字；只在需要时开启，关闭后控制接口停止。
- Claude Code 是 Anthropic 的商业软件，本 APK 不打包它，首次安装时由手机
  从官方发布地址下载并校验 SHA-256；请遵守 Anthropic 的使用条款。
