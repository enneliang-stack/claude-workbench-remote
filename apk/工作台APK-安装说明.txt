Claude 工作台 · 手机远程控制（通用版 APK）
============================================

文件：Claude工作台-通用版-1.0.10.apk（约 49 KB）
包名：com.missyao.claudeworkbench
版本：1.0.10（versionCode 11）
最低系统：Android 8.0（API 26）
签名：本地自签名。本仓库的预编译 APK 和原来的个人版使用同一签名，
      可以直接覆盖安装 1.0.9；如果你的手机提示签名不一致，先卸载旧版再装。

和旧个人版的区别
----------------
- 不再内置任何人的 Tailscale 主机名、局域网 IP 或 token。
- 第一次打开会弹出「连接工作台」，把电脑上「远程访问.cmd」打印的
  手机地址（包含 token）粘贴进去即可；地址保存在手机本地。
- 连接失败页有「重新配置地址」，可以随时换地址。
- 其它功能和旧版一样：相册图片、任意文件上传、引用电脑文件、
  下载/打开/删除文件、已下载文件页、长对话分页、Markdown、代码复制。

安装
----
1. 在电脑上装好工作台客户端 1.1.23，并运行
   `install\一键安装手机远程控制.cmd`。
2. 重启客户端，双击客户端的「远程访问.cmd」，记下打印的手机地址。
3. 把 APK 传到手机（QQ/数据线/网盘/浏览器下载）。
4. 允许文件管理器「安装未知应用」，覆盖安装旧版。
5. 打开 App，粘贴第 2 步的地址，点「连接」。

地址示例
--------
家里 Wi-Fi：
  http://192.168.x.x:4711/m/index.html?token=你的令牌

出门（Tailscale）：
  https://电脑名.xxxxx.ts.net/m/index.html?token=你的令牌

只填 https://电脑名.xxxxx.ts.net 也可以，App 会自动补 /m/index.html；
但没有 token 时会停在令牌输入页。

Tailscale
---------
本仓库不再附带 105 MB 的 Tailscale 安装包，请从官方下载：
  https://tailscale.com/download/android
电脑和手机登录同一个账号，手机开启 Tailscale 才能用外网 HTTPS 地址。
如果手机解析不了 *.ts.net，开启 Tailscale 的 “Use Tailscale DNS” 或
在管理后台打开 MagicDNS。

常见问题
--------
- 打开一直转圈/显示连接不上：
  1. 手机 Tailscale 是否开启并登录；
  2. 是否同时开了其它 VPN/加速器（会占用 VPN 通道，先关掉）；
  3. 电脑是否开机联网，客户端是否在运行；
  4. 客户端是否已运行「远程访问.cmd」开启远程监听；
  5. 地址是否完整（含 token）。
- 点「打开」APK 提示授权：允许「Claude 工作台」安装未知应用，
  再点一次打开。
- 手机文件管理器搜不到 App 内下载的文件：
  文件在 App 私有目录，用工作台搜索栏右侧的 ⇩「已下载文件」页面管理。
- 想改用 Chrome 的 PWA：手机 Chrome 打开 HTTPS 地址，菜单里选
  「安装应用」，效果和 APK 类似，不需要装 APK。

安全
----
- 地址里的 token 就是登录密码，不要发给别人。
- 局域网 HTTP 不加密；只在自己家的 Wi-Fi 或 Tailscale 下使用。
- 公共 Wi-Fi 下不要开启远程访问。
